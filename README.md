# Tick Replay — 歩み値リプレイ

歩み値CSV（ティックデータ）を読み込み、ローソク足と歩み値パネルを時系列で再生するローカルWebアプリ。

## 起動

```bash
npm install
npm run dev     # http://localhost:5173/
```

`public/data/qr-6330-20260828.csv` を起動時に自動で読み込む。
別の銘柄・日付は右上の **CSVを開く** から選択（UTF-8 / Shift_JIS どちらも可）。

## 機能

| 項目 | 内容 |
|---|---|
| 再生 | ▶ / ⏸（Space キーでも切替）、⏮ 先頭へ、⏭ 1約定ずつ送り |
| 倍速 | ×1 / 2 / 5 / 10 / 30 / 60 / 120 / 300 |
| 足種 | 1秒 / 5秒 / 15秒 / 30秒 / 1分 / 5分（再生位置を保ったまま切替） |
| シーク | 下部スライダーで任意の約定位置へジャンプ |
| 空白スキップ | 3秒以上約定が無い区間を早送り（昼休み 11:30→12:30 など） |
| 歩み値 | 直近200件を新しい順に表示。上げ=赤 / 下げ=青、大口は株数を強調 |
| 指標 | 現在値・始値比・高値・安値・出来高・VWAP をリアルタイム更新 |
| ジッター | 同一秒のティックを秒未満にばらけさせ、実際の板に近いリズムで流す |

## CSVフォーマット

ヘッダー名で列を判定する（`値段` / `株数` / `金額` / `時刻`。価格・数量・時間などの別名にも対応）。
ヘッダーが無い場合は `値段,株数,金額,時刻` の並びとみなす。

```csv
値段,株数,金額,時刻
2781,272300,757266300,15:30:00
2780,100,278000,15:24:59
```

- 新しい順（降順）で出力されていても自動で時系列に並べ替える
- 日付と銘柄コードはファイル名から推定する（`qr-6330-20260828.csv` → 6330 / 2026-08-28）
- 時刻は JST の壁時計をそのまま UTC 秒として保持し、チャートに同じ時刻で描画する

## 構成

```
src/
  lib/csv.ts        CSVデコード（UTF-8/Shift_JIS自動判別）とティック化
  lib/jitter.ts     同一秒ティックの秒未満オフセット生成（決定的ランダム）
  lib/candles.ts    ティック→ローソク集計（逐次追加 / 一括再構築）
  lib/colors.ts     配色（上げ=赤 / 下げ=青）
  hooks/useReplay.ts  再生エンジン: 仮想時計・倍速・空白スキップ・シーク
  components/Chart.tsx    lightweight-charts v5 ラッパー（ローソク＋出来高）
  components/Tape.tsx     歩み値パネル
  components/Controls.tsx 再生コントロール
```

### 再生エンジンの考え方

- `requestAnimationFrame` で仮想時計を `経過秒 × 倍速` だけ進め、`tick.rt <= 仮想時計` のティックを消化する
- 1フレームあたりの処理数に上限を設け、超えたら時計を巻き戻して取りこぼしを防ぐ
- UI state の書き戻しは 60ms 間隔にスロットリング（チャートへの反映は毎フレーム）
- 巻き戻しシークは 0 から再集計して `setData` で差し替えるため、常に前方再生と同じ結果になる

### 秒未満のジッター

歩み値CSVの時刻は秒までしか無いため、素直に再生すると1秒分の約定が1フレームにまとめて流れる。
かといって均等割（`1 ÷ 件数`）にすると、メトロノームのように不自然な等間隔になる。

そこで `lib/jitter.ts` が、実際の板と同じ「かたまりと空白」を持つ到着間隔を生成する。

- 指数分布から `件数 + 1` 本の間隔を引き、累積して 0〜1 秒に正規化する
- 指数を `BURST = 1.6` 乗して裾を重くし、連続約定（数ms間隔）と空白を作る
- 小数第3位で切り捨て。最後の1本も必ず 0.999 以下に収まり、次の秒へはみ出さない
- 乱数はその秒の値を種にした決定的 PRNG なので、**同じCSVは何度読み込んでも同じ再生になる**

結果は `tick.rt`（replay time）に入り、再生時計だけが参照する。
`tick.t` は実時刻のまま残るので、歩み値の表示時刻もローソクの足の区切りも一切ずれない。

```
1秒に8件あった場合のオフセット (ms)
  均等割  :    0 125 250 375 500 625 750 875
  ジッター:    3   4 309 324 598 717 718 718
```
